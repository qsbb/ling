# 许可说明

本项目采用 **GNU AGPL-3.0-or-later**（全文见 [LICENSE](../LICENSE)）。

## 一句话

你可以随便用，但**不能拿了之后不开源**。

## 具体能做什么

| 你想做什么 | 可以吗 |
|---|---|
| 自己部署、自己用、随便改 | 可以 |
| 改完自己留着，不对外提供 | 可以（AGPL 只在分发或对外提供服务时触发） |
| 改完再分发 | 可以，但必须同样以 AGPL 公开源码 |
| 部署成服务给别人用 | 可以，但必须把修改后的完整源码提供给使用者 |
| 闭源商用 | 不行，需要商业授权 |

## 为什么是 AGPL 而不是 GPL

这是个服务端项目。GPL 的 copyleft 只在分发二进制时触发——别人把它架在服务器上
对外提供服务，一行代码都不用公开。AGPL 补上了这个缺口：通过网络提供服务也算分发。

## 双许可

遵守 AGPL（公开修改）就免费使用。

要闭源使用——比如做进商业产品而不公开源码——需要另行取得商业授权。
这种「开源 + 商业授权」并行的做法（MySQL、GitLab 等都是这个模式）能同时满足两件事：
社区可以自由使用和改进；不愿意遵守开源的，只能来谈授权。

商业授权请通过 GitHub Security Advisory 私下联系作者。
未经书面授权的闭源分发属于违反本许可。
