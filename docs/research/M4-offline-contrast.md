## 0. 为什么要用线下做对照

反例里的失败——「把一串旧话题接下去」——在**线下几乎不会发生**。原因不是人更
聪明，而是线下提供了 IM 缺少的**共同在场线索**。把这些线索列清楚，才能反过来
看清 IM 里模型缺了什么、该用什么信号补。

---

## ① 研究 / 观察情境

### S4.1 同处时的承接：多通道同时在线

线下承接一句话，靠的不只是词：

- **视线/朝向**：对方看着你、身体转向你 → 这句对你说，且在延续当前话题。
- **指示手势**：指着桌上的文档说「第二项」→ 「第二项」的指代对象当场可见。
- **共同注意**：两人都在看同一块屏幕/同一张纸 → 指代有共享物理锚点。
- **语气与停顿**：句尾上扬表示提问，停顿表示话没说完。

**合成情境 F（线下指代靠共同在场解决）**

```
两人同时看着桌上的打印稿。
甲（指着第二行）：这个要改。
乙：哪个？
甲（手指没动）：就这个。
```

「这个」的指代对象由**手指 + 共同注意**确定，不需要语言里出现先行词。
换成 IM：「这个要改 / 哪个？ / 就这个」——最后一个「这个」在没有图片/引用时
**指代落空**（见 M1 B1.2）。这是 IM 与线下的关键差异。

### S4.2 打断与修复

线下话题切换常由**打断**显式标记：

```
甲：那个方案我列了四项……
乙（插话）：先别说那个，看这个。
甲：好，看这个。
```

「先别说那个」是一个**显式的换题指令**，附带身体动作（插话、转向）。
线下人立刻知道旧话题被挂起。

IM 里的等价物不存在：消息是**排队**的，不能真正打断。后来者发「先别说那个」
仍然排在时间线末尾，前面那句「列了四项」还留在窗口里，模型可能继续接它。
**[推理] IM 的异步性把「打断」退化成了「追加」，丢失了话题终止信号。**

### S4.3 共同在场线索的类型的

| 线索 | 线下是否可得 | IM 中是否有等价物 |
| --- | --- | --- |
| 视线/朝向 | 是 | 无（在线状态只是弱近似，见 M1） |
| 指示手势 | 是 | 无（引用/@ 是弱近似，见 M2） |
| 共同注意对象 | 是 | 无（共享文档链接勉强近似） |
| 语气/停顿 | 是 | 无（标点勉强近似，弱） |
| 即时打断 | 是 | 无（只能追加消息） |
| 时间戳 | 隐含「刚刚」 | 显式，且可跨天 |

### S4.4 线下也有「延迟」，但性质不同

线下可以沉默几秒再答，但**在场感持续**——沉默期间双方仍在同一场景，
话题上下文不断档。IM 的隔天断档是**场景切换**，不只是时间间隔。
这解释了为什么 M3 里「隔天首条多为新开场」：线下没有等价的「隔天同场」。

## ② 可观察行为（可写成回放判据）

**B4.1 指代解决方式的差异**
- [观测] 同一段对话「这个要改 / 哪个？ / 就这个」。
- 判据：线下情形有共同在场线索时，「就这个」可解；IM 情形无引用/图片时，
  「就这个」应判为**指代落空**并触发向前扩展或澄清请求。
- 区分力：若两种情形模型给出相同回复，说明它没用「是否有共同锚点」这一差异。

**B4.2 换题标记的缺失**
- [观测] IM 里出现「先别说那个 / 不聊这个了 / 换一个」。
- 判据：这类文本是**显式换题指令**，应抑制对旧话题的续接。若模型仍接旧话题，
  说明它把否定词当普通文本处理。
- 反例：把「先别说那个」换成「那个不错」——后者不是换题，若判据也抑制续接，
  说明它测的是「那个」这个词而非「否定换题」。

**B4.3 在场线索的弱化映射**
- [观测] 快照里是否有「在线状态 / 引用 / @ / 共享附件」等弱近似字段。
- 判据：这些字段**不能当作线下在场的等价物**。若模型把「在线」当成「对方正在
  看且会立刻接上一句」，属于过度推断；应把它们作为弱先验，权重低于显式锚点。

**B4.4 沉默 vs 断档**
- [观测] 线下沉默几秒 / IM 隔天断档。
- 判据：线下沉默期间话题上下文**不断档**（仍同场）；IM 隔天断档**默认新开场**
  （见 M3 B3.1）。若两者被同等处理，说明模型没区分「同场沉默」和「场景切换」。

## ③ 对 Ling 上下文取数的启示

1. **IM 缺少线下四件事：共同注意、指示、即时打断、持续在场。** 模型的上下文
   取数必须显式补上替代信号：
   - 指示 → **引用/@**（显式指针，见 M2）；
   - 共同注意 → **共享附件/链接**（若有）；
   - 打断 → **显式换题文本**（「先别说那个」，见 B4.2）；
   - 持续在场 → **时间位置 + 锚点**（见 M3）。

2. **区分「隔天仍在续聊」与「几秒内已换题」的线下对照启示：**
   线下靠**场景连续性**判断续聊；IM 没有场景，只能用**文本锚点 + 时间位置 +
   引用结构**重建。因此：
   - 几秒内换题 → 线下等价「当场插话换题」，有显式标记；IM 里靠最近气泡 +
     换题词识别。
   - 隔天续聊 → 线下等价「第二天回到同一张桌子前继续」，需要明确说「昨天那个」；
     IM 里必须看到同样的显式找回词才判续聊。
   - **没有这些标记时，IM 的默认应和线下「换了场景」一致：新开场，不续旧话。**

3. **「嗯」「？」的线下/IM 差异：**
   - 线下「？」常伴随皱眉/前倾，明确指向**刚说的那句**；
   - IM 几秒内「？」是澄清刚才那句（M3 B3.3）；
   - IM 隔天「？」失去身体线索，若无锚点则不应自动指向旧话。

4. **不要把弱近似当等价。** 在线 ≠ 在场，引用 ≠ 手指，标点 ≠ 语气。
   取数里这些字段只能做弱先验，决定接续的应是显式锚点和时间位置。
