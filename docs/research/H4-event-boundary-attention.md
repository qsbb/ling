# H4 · 事件边界与注意力：分段标记如何影响旧信息的可及性

> 研究范围：事件分段（event segmentation）与边界处记忆/注意的关系——叙事或对话被压缩进摘要、提示词后，时间词、话题转换、段落、列表这类边界标记如何改变后续信息的可及性与被续接倾向，以及弱边界下旧事件为何仍占据注意。
>
> 材料全部为公开文献与合成情境，无真实用户数据。反例判定以提示词快照/回放为准，截图只说明表现，不引用其细节。
>
> 置信度：**[实测]** 本轮已联网核实的文献元数据、或可由快照/回放直接看到的行为；**[推理]** 基于 IM 机制的归因，可被反例推翻；**[转述]** 文献结论，均标「未核实」（本轮未逐篇读全文）。

## 研究情境

[转述，未核实] Newtson 范式让被试观看**日常活动视频**（如某人做家务、泡咖啡），要求他们按「有意义的活动单元」切分，切分点即主观事件边界；分析单位是边界位置、单元粒度、以及不同被试切分的一致性（inter-rater reliability）。[实测：元数据；转述：实验细节未核实。]

[转述，未核实] Zacks 与同事的事件分段研究覆盖**电影片段与日常活动视频**，也扩展到**文本阅读**（读者按叙事场景转换分段）；被试多为大学生或普通成人。分析单位包括边界位置、边界处的时间排序判断（temporal order memory）、再认/回忆准确率，以及 fMRI 下边界相关的神经响应。[实测：书目；转述：被试与分析单位未核实。]

[转述，未核实] Swallow, Zacks & Abrams (2009) 用行为实验检验「感知到的事件边界影响记忆编码与更新」：在自然活动序列中，边界处项目的时序记忆更差，而新事件开始的信息被更新进工作记忆。[实测：书目与题名；转述：具体实验材料与被试未核实。]

[转述，未核实] Radvansky 组的相关研究（含 2011、2016 的 *Event boundaries and memory improvement* / *Event boundaries and memory for event information*，见 Crossref [10.1016/j.cognition.2015.12.013](https://doi.org/10.1016/j.cognition.2015.12.013)）多用**叙事文本与电影**，考察事件边界对情境模型（situation model）更新与时序记忆的双重作用。[实测：书目；转述：材料与被试未核实。]

这些研究的共同结构是：连续输入 → 被试在边界处切分 → 测边界前后项目的可及性。它们研究的是**人的感知与记忆**，不是 IM 机器人的上下文窗口；这一差别在「适用边界」里展开。

## 可观察行为

以下行为以编号列出，括号内的置信度针对「文献是否支持该方向」，不是针对 Ling 的实现。

1. **[转述，未核实] 边界处信息更容易被更新、边界前信息时序记忆变差。** 事件边界触发工作记忆/情境模型的更新，边界前项目的时序判断准确率下降，新事件的信息被编码。可回放观察：摘要里是否出现「时间锚点 + 新话题起点」，以及旧话题细节是否在压缩中被丢弃。

2. **[转述，未核实] 跨边界的旧信息可及性降低。** 一旦被切到新事件，旧事件的细节更难被提取，需要显式线索才能找回。可回放观察：给用户一个无锚点的短句时，模型是否仍把很久以前的话题当作当前指代对象。

3. **[推理] 弱边界/列表化呈现使旧条目仍保持高可及性。** 段落、时间词、话题转换是强边界；把多件事压成并列列表、去掉时间锚点，则边界标记弱，旧条目与当前上下文在文本上平级。推测此时旧条目更易被「相关性」检索捞回，而非被边界隔离。此项为对 IM 的推理，文献未直接测试列表提示词。

4. **[转述，未核实] 事件边界与注意力/预测误差同步。** 边界处伴随预测误差上升与注意转移，人对边界处变化更敏感。可回放观察：话题转换词（「对了」「话说回来」「前天」）之后的信息是否被当作新事件处理，以及模型输出是否围绕转换后的话题展开。

5. **[推理] 旧话题「一旦进过对话」就更易被续接，本质是摘要常驻 + 弱边界。** 在 Ling 里，摘要永不过期且每轮无条件随上下文带出（见 LEAD-notes §2：[实测] 代码路径），它把旧事件以文本标记形式持续呈现；若同时缺少「现在已换题」的强边界，旧条目在注意上并未真正退出。这是本方向对反例的核心解释，仍须回放验证。

## 适用边界

可外推的部分是**方向性结论**：强边界（时间锚点、话题转换、段落分隔）倾向于把信息切成不同事件，降低跨边界旧细节的默认可及性；弱边界使旧条目与新上下文平级、更易被续接。这个方向可以指导「提示词里要不要显式写时间/话题边界」的设计假设。

不能外推的部分必须明说：

- **材料不同。** 原始实验多为视觉/叙事材料（日常活动视频、电影、阅读文本），不是即时通讯对话；IM 消息是短、碎、多话题交织的文本流，边界标记稀疏且由用户随意给出。[实测：文献元数据；推理：差异本身是观察，不是文献结论。]
- **记忆载体不同。** 机器人没有人的工作记忆，它的「旧信息可及性」是**外部存储 + 检索/上下文装配**的结果（摘要、embeddings、召回），不是生物记忆的衰减与更新。把「边界处记忆更新」直接当成「改向量库」是范畴错误——文献里的更新是注意与编码，工程里的更新是写库。
- **边界性质不同。** 提示词里的事件边界是**文本标记**（「前天」「对了」、段落、列表），不是感知分段；人脑的边界来自感知预测误差，文本标记只是它的符号代理，模型对标记的响应不等于人的分段机制。
- **因此不能外推的部分**：不能从这些文献反推具体参数（摘要保留几条、召回阈值多少、隔多久算新事件），不能声称「模型一定按人类边界分段」，也不能用它们替代本项目回放集的实测。ATTENTION-DESIGN §9 已立过同样的规矩：不从文献反推参数，参数唯一正当来源是真实会话回放。

## 对 Ling 反例的映射

反例（[合成]）：用户先问「你还记得前天聊了什么吗」，后来发「早上好」，再对刚才问候回「？」。Ling 先解释问候，又继续列很久以前的四项产品需求。判定以提示词快照/回放为准，截图只说明表现。

下面逐条写出该研究**预测什么**、反例**符合还是违背**、置信度。

1. **强时间边界应隔离旧事件。** 研究预测：带时间锚点（「前天」）+ 话题锚点的提问是一个显式找回事件，它把「前天那四项需求」激活为当前事件；但后续「早上好」构成新事件的强边界，旧事件应被切出、可及性下降。[转述，未核实：文献方向] 反例里 Ling 在解释问候后仍列出四项需求，说明旧事件**未随新边界退出**——**符合**「弱边界下旧事件仍占注意」的预测，但**违背**「强边界应隔离旧事件」的预测。置信度：**[推理]**，须查快照确认四项需求来自摘要 lane 还是召回 lane。

2. **「？」应接最近的「早上好」，不接旧事件。** 研究预测：紧邻短回复属于当前事件内的澄清，边界前信息（问候）比更早事件更可及。[转述，未核实：方向] 反例中 Ling 先解释问候（这一步符合），随后转到旧需求（这一步违背）。即**部分符合、部分违背**；违背部分指向「当前事件建立后旧事件未被抑制」。置信度：**[推理]**，依赖「？」与「早上好」的时间相邻性由回放确认。

3. **弱边界/列表化让旧条目持续高可及。** 研究预测：若旧需求在提示词里以并列列表形式常驻、无「现已换题」标记，则它与当前上下文平级，最容易被续接。[推理：对 IM 的外推] 反例中四项需求被连续列出，形态正是列表化——**符合**该预测。置信度：**[推理]**；LEAD-notes §2 的「摘要每轮无条件带出」是 [实测] 代码路径，但「列表化导致续接」尚未实测。

4. **边界标记弱时旧事件仍占据注意。** 研究预测：缺少段落/时间/话题转换标记时，旧事件不会自动退出注意，需要显式边界或检索抑制。[转述，未核实：方向] 反例里「早上好」是唯一新边界，且不含时间/话题锚点，属弱边界；Ling 续接旧需求——**符合**该预测。置信度：**[推理]**，这是本方向对反例最贴合的一条解释。

5. **时间断档本身是边界信号，但非充分条件。** M3 已指出：隔天首条多为新开场，Δt 不可单独作判据，需锚点/引用/元话语。[观测：M3 推理 + 合成情境] 反例中「早上好」是隔天开场但无锚点，按 M3 应判新开场而非续旧话；Ling 续接旧需求——**违背**该预测。置信度：**[推理]**，与第 1、4 条同指一个现象，只是从「跨时段」角度表述。

6. **边界与注意转移同步。** 研究预测：话题转换后注意应转向新话题。[转述，未核实：方向] 反例中 Ling 先解释问候（注意确实转到新话题），但随即回到旧需求（转移不彻底）——**部分符合**。置信度：**[推理]**；「注意转移」在模型里没有直接观测量，只能从输出话题分布间接推断，不可当作实测。

综合判断：[推理] 反例最符合的预测是「弱边界下旧事件仍保持高可及性」；最违背的是「强边界/新开场应隔离旧事件」。两条并不矛盾——它们共同指向一个机制缺口：**Ling 把旧话题以无过期摘要 + 列表形态常驻，却缺少把它标记为「已结束事件」的边界信号**。这是归因，不是实测结论。
