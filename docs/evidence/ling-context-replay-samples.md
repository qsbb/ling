# Ling 上下文研究 · 可复用中文回放样本（最小集）

> 性质：全部为 **synthetic（合成）**，不来自真实用户、不来自生产库。QQ 号用假号 `100200300` 一类。
> 目的：在**同一模型、同一历史**下比较不同当前消息造成的上下文选择，以及不同取数策略造成的回复差异。
> 强制要求：回放记录必须附**实际模型输入**（编译后的 messages / prompt snapshot）与**实际回复**；
> 凡未调用模型、只用规则推演的结果，必须标 `SCRIPTED`，不得冒充真实输出。
>
> 观测对象：仓库 `/Users/lingxi/project/ling`，HEAD 以每轮记录为准；研究起始 HEAD=`de43cbe79a78e0c01f7821470500eaa04ea79497`。
> 本文只给样本与判据，不代表已跑过真实模型。

## 样本集编码

| 编号 | 场景 | 关键配对 | 期望行为（应然，待回放验证） |
|---|---|---|---|
| A1 | 时隔很久但明确续聊 | 对照 A2 | 「接着说前天那个方案」→ 有明确时间/话题锚点，允许找回旧内容 |
| A2 | 刚换话题 | 对照 A1 | 同一旧历史 + 「刚说了句早上好」→ 不应续旧方案 |
| A3 | 异步引用 | 对照 A4 | 「回复→某条旧消息：这个后来怎样」→ 指向被引用的那条 |
| A4 | 简单问候 | 对照 A2 | 「早上好」→ 接眼前问候，不召回显著旧事 |
| A5 | 短问号 | 同句隔天配对 | 「？」在刚收到问候后→澄清刚才那句；隔天无锚点→不可判定为新开场/澄清 |
| A6 | 多个相似旧话题 | 同句不同锚点 | 「上次那个方案」有多个候选→优先最近显式引用，或表明不确定 |
| A7 | 群聊交错 | 说话人与引用配对 | 两个话题并行 + @ → 跟对说话人和被引用消息，不按气泡相邻硬接 |
| A8 | 显式换题 | 与 A1 配对 | 「先别说那个」→ 抑制旧话题续接 |

## 最小对话模板（相对时间；可用任意固定日期替换）

记号：`U` = 用户，`L` = Ling，`T` = 相对时间起点，`Δ` = 相对间隔（不把秒数当 Ling 参数）。
每条消息建议记录：platform_message_id（假值）、sender_subject_id、text、reply_to、mentions、created_at。

### A1 · 很久后续聊（明确锚点）

```
T+0     U: 前天那个产品方案我整理了四条，第一条是提醒偏好
T+1m    U: 第二条是多窗口合并
T+2m    U: 第三条是群聊引用，第四条是主动开场
T+3m    L: 记下了，四条都在这
T+2d    U: 早上好
T+2d+5s U: 接着说前天那个方案
```

注意：`早上好` 与 `接着说前天那个方案` 是**两条独立消息**。不要把「早上好」的回复表现当作「接着说」的输入事实。

### A2 · 刚换话题（无锚点）

```
T+0     U: 前天那个产品方案我整理了四条，第一条是提醒偏好
T+1m    U: 第二条是多窗口合并
T+2m    U: 第三条是群聊引用，第四条是主动开场
T+3m    L: 记下了，四条都在这
T+3m+4s U: 早上好
```

### A3 · 异步引用

```
T+0     U: 上次说的四份需求，第三条我改了
T+1d    L: 好，我记得是群聊引用那条
T+1d+2h U（回复→T+0那条）: 这个后来怎么处理的？
```

### A4 · 简单问候

```
T+0     U: 早上好
```

或接在 A1 历史之后，只发 `早上好`。

### A5 · 短问号（两种位置，必须用同一句、同一历史）

```
# 位置一：紧跟问候
T+2d    U: 早上好
T+2d+3s U: ？

# 位置二：隔天无锚点
T+2d    U: 早上好
T+3d    U: ？
```

### A6 · 多个相似旧话题

```
T+0     U: 方案A：提醒偏好
T+1m    U: 方案B：群聊引用
T+2m    U: 方案C：主动开场
T+3m    L: 三个方案我都记下了
T+1d    U: 上次那个方案，你觉得哪个最急？
```

### A7 · 群聊交错

```
G1（synthetic，假群号 100200300）
T+0     阿岚: 周五评审改到下午了
T+6s    小满（回复→阿岚那条）: 我改日历
T+10s   Kiki: 午饭谁一起？
T+13s   阿岚: 我
T+16s   L: 那我订四份
T+20s   老周: @Ling 评审材料你整理吗？
```

### A8 · 显式换题

```
T+0     U: 接着说前天那个方案
T+5s    U: 先别说那个，说今天的天气
```

## 判据（先看判据，再看实现）

每条判据必须回答：哪个错误实现会让它失败？区分力不足的判据应标 `无法证明`。

| 判据 | 输入 | 正确行为 | 错误实现会怎样 |
|---|---|---|---|
| C1 显式找回 | A1 | 编译输入含旧方案的原文或摘要，回复接方案 | 只看最近一轮 → 答不出方案 |
| C2 问候不误召回 | A2、A4 | 编译输入不因问候触发旧事大幅召回；回复只接问候 | 宽泛语义召回 → 列四项旧需求 |
| C3 短问号定位 | A5 位置一 | 澄清刚才那句「早上好」 | 宽泛召回 → 旧事；只看字面 → 无所指 |
| C4 异步引用 | A3 | 展开被引用那条，回复针对「第三条」 | 按气泡相邻 → 回最近一句 |
| C5 多候选 | A6 | 识别歧义或指向最明确锚点 | 固定取最显著/最早 → 指错方案 |
| C6 群聊说话人 | A7 | 跟对 @Ling 的老周，不被午饭话题带走 | 按最近气泡 → 回午饭 |
| C7 换题抑制 | A8 | 停止旧话题续接 | 仍接方案 → 误续 |
| C8 条件式时间 | 同一「？」在 A5 两位置 | 位置不同解读不同；不能给固定秒数阈值 | 固定时长阈值 → 一种位置必错 |
