## 行为边界

- `/v1` 框架校验、路由找不到、方法不支持和未处理异常统一为 `ErrorResponse`。
  错误保留追踪号，405 保留 `Allow`；参数错误不回显原始值。媒体模式必填、不可逆工具走提议确认
  的固定提示仍保留。前端按状态码识别旧服务端或代理的非契约响应。
- 管理写操作要求 `owner`。实际使用 Cookie 时校验同源，同时带 Bearer 不会跳过检查；仅使用
  Bearer 不要求 `Origin`。无请求体的删除和重置不需要空 JSON；音色上传保持 multipart。
- 实例级统计也是运维数据，不能用普通账号读取；日志保留原 `owner`/`admin` 边界。
  个人会话、记忆和偏好仍按原有归属授权。OneBot、QQ 等接入器的回调协议与可选凭据不变。
