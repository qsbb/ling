### A1.2 但发现一处实质越界（实测，需修正）

**`cross-session-async.md` L94 与 `private-chat.md` L99-103 的"硬结论"**：

> "硬结论（[推理]）：`context.py:1550–1571` 用当前原文做 query；「？」不满足跳过 → 走宽泛召回；
> 又不是 `needs_recent_topic` → 不拼上一句。这条路径最容易召回显著旧事。"

这段虽然打了 [推理] 标签，但：
1. 前半句是**代码路径事实**（我复核属实：D 组 §5.1/5.2 与我的 grep 均证实），可以保留；
2. 后半句"这条路径最容易召回显著旧事"是**因果归因**，没有任何召回日志/证据 hits 支撑——
   按 V1/V2，它需要 `evidence` 车道的实际快照（是否真的命中旧事、命中了什么）才能成立。
   仅凭"走宽泛召回"推不出"最容易召回显著旧事"——这是把**路径存在**误当**结果发生**。
3. private L99 更把它写进"结论（[推理]）"，并在 L101 说"两类？在输出上都可能表现为列旧需求"——
   "可能"二字救了它，但 L94 的"最容易"是隐含比较级，强于现有证据。

**裁决**：这属于"把路径推理包装成结果断言"的边缘案例。按 A4（格式即置信度），
"硬结论"三个字 + 因果比较级使读者会把它当已验证事实。建议改为：
"代码路径上『？』会触发自动召回（[代码]）；**是否真的召回旧事、是否因此误续，需要 annotated 快照才能判定**（当前未测）。"

### A1.4 对既有竞争解释排序的影响

**D 明确区分了五类旧内容**（正面回答 lead 的核对点）：
1. 同窗口原文（`messages_for_prompt`，按 `window_id` + 摘要水位）；
2. 摘要（`window_contexts.summary`，常驻、不受 TTL）；
3. 长期记忆召回（`evidence` 车道，12→3、420 token、非 sealed）；
4. 引用消息（**否定结论**：入站 reply_to 无 prompt 块；出站 `[msg_id:]`/`[quote:]`）；
5. 显式换题（**否定结论**：无独立 topic-switch 信号，只有 `needs_recent_topic`/`wants_history` 正则）。

**配置存在 ≠ 主链接线**：D §9 逐项标"实际被本文件消费的"，没有把 `config.py` 里存在但没被读的键当证据（对比 C 组对 `group_mention_on_reply` 的"只存不用"判定）。这条做得比一般取证文档好。

### A2.2 不能证明什么（关键）

1. **D 全是静态代码取证，零运行期证据**：没有一次 `compiled.annotated` 快照。
   "摘要每轮无条件注入"是代码事实（能证明）；"某条旧需求真的因此进了某轮 prompt"是运行期事实（**未测**）。
   按 V1，后者必须快照。
2. **"召回 12 候选→精筛 3"只到候选上限与过滤规则**（D §5.3 自标"[推理·中]：具体排序权重在 memory service，未深入逐行核对"）——
   **不能证明** BM25/向量/rerank 实际把哪条排进前 3；对 E1（相似度驱动）的排序解释只提供入口，不提供结果。
3. **否定结论"话题切换是自然发生、不需要新窗口"（D §7/结论 9）是推理档**：
   它由"无 topic-switch 信号 + 有摘要水位/预算/召回"推出，逻辑成立；但"自然淡出旧话题"是否有效，
   需要回放证明旧话题确实淡出——当前无数据。文档已标"推理/高"，符合 §8，**但不得被下游读成实测**。
4. **D 与 C 的交叉印证**：C 说"入站无 TTL、无话题切换"，D 说"编译期无 topic-switch 信号"——
   两份独立取证互相支持，但这仍是**同一代码库的两处静态观察**，不是两次独立实验（A3：不要当成两个证据源）。

### A2.3 一个需在最终报告统一的口径冲突（实测）

D §5.1 说 sealed 关闭长期记忆；D §7/结论 9 说 "sealed 模式才会主动切断跨窗口旧内容"。
但 C §3.3 说"入站侧没有显式话题切换命令"，两者并不矛盾（一个在编译期、一个在入站期），
**容易混淆的是"切窗口档位"与"开新窗口"**：D 把 sealed 叫"切窗口档位"，C 说"没有开新窗口入口"。
下游写方案时若把 sealed 当作"新窗口"的等价物，会重犯 AGENTS.md 指出的"名字比实现强"错误。
建议在最终证据索引里明确：**sealed = 隔离档位，非新窗口；入站无新窗口动作。**

## A3. 修正后的最值得补实验（纳入 A1.4 的新发现）

原判据 §10 的 2×2 实验需加第三因子 C（引用正文是否注入），变为 **2×2×2 精简版**：

| 格 | A 旧片段在快照 | B 用户真延续 | C 引用正文可见 | 预测区分 |
|---|---|---|---|---|
| 1 | 有 | 无锚点 | — | 若续旧 → E1/E6 支持，E3/E5 反驳 |
| 2 | 有 | 有锚点 | — | 若续旧且针对锚点 → E5 支持 |
| 3 | 无 | 无锚点 | — | 若仍续旧 → E6（模型惯性）成立，其余全降级 |
| 4 | 有 | 引用结构在 | 正文**未**注入 | 若答非所问/取最近 → E1'（锚点悬空）证实 |

理由：D §6.2 证明"用户引用"在内核里没有结构化块，格 4 是**当前实现真实存在的失败模式**，
不是假想反例。若只跑原 2×2 会漏掉它。
