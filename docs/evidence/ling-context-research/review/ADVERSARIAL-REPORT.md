## 3. 变异式反驳（两条，取反关键前提后看原结论是否成立）

### 变异 1：把"真实模型回放"取反为"脚本模拟输出"

- **取反对象**：02-options §5.1 要求区分真实输出与 SIMULATED；假设最终只有 `ScriptedProvider` 的脚本回复。
- **原结论**：若仍声称"B 方案比 A 更少误提旧事、换题更自然"——这个结论**不成立**。脚本按规则产出字符串，只能证明"在规则 R 下输出字符串 S"（M2）。M-1/M-2 的"回复针对锚点/不含旧事"若是脚本按模板实现的，红绿只反映模板，不反映模型理解（M4）。
- **成立的部分**：M-9（引用 id 不可用时是否静默取最近）、M-11/M-12（长度/调用数）是**管线属性**，脚本回放仍可验证——这说明这些判据与模型无关，本来就应写成规则断言（变异 1 反而帮它们正名）。
- **判定**：options §5.1 的 SIMULATED 标记要求与 §3 清单第 1 条（"B 在真实模型上比 A 好"无法证明）**方向正确**，但必须在最终报告中保持，不得被"全绿"覆盖。

### 变异 2：把"人类未完成意图产生续接压力"取反为"人类并没有这种压力"（H 类前提取反）

- **取反对象**：human 04 §2.4/§5.2 与 human 02 Q4 的核心前提——"未闭合意图在边界处保留续接压力"。
- **若该前提为假**：doc04 的"未完成事件在边界处的持续性"、doc02 的"未完成序列期待回答……插进早上好不消失"、doc03 的"未完成意图"三条解释**同时失效**。此时旧话题被续接的最简解释退化为 E1（召回相似度）/E6（模型惯性），即：不是"人类式的未闭合压力"，而是"旧片段恰好被检索到、LLM 顺势续写"。
- **原结论是否成立**：human 四篇的**可观察判据层**（"看显式回指/闭合信号/针对性"）仍成立——因为它是描述性的，不依赖压力机制；但它们的**机制解释层**不成立。这正好验证 A3：判据与机制必须分开写。
- **判定**：四篇都把机制标为"推理/推测"，所以取反后**没有一句被写成事实的机制被推翻**——这是它们的纪律之处。唯一例外是 doc03 L132/L146（"错误绑定"写成事实），在取反后依然站不住，因为它本来就无证据。

## 4. 「旧话题为何容易被继续接下去」竞争性解释排序

排序依据：是否有对照组证据、是否能排除其他解释、是否依赖人类参数误用。当前全部为**推理档**（无回放数据）。

| 排名 | 解释 | 证据状态 | 为什么排这个位置 |
|---|---|---|---|
| 1 | **E3 未完成序列/意图悬置**：旧问题未得回答，结构上"期待"续接（human02 Q4-2、human03 §5.2-3、human04 §5.2） | 三篇 human 独立同向推理，但都标"推测" | 跨三篇一致、可观察判据最明确（是否有 closing implicative / 未回答的问句）；但**无对照实验**，且人类机制前提被变异 2 取反后失效 |
| 2 | **E1 召回相似度驱动**：旧片段因关键词/嵌入相似被检索到，模型顺势接上（source C Q2 条件链、D 组待审） | 源码侧有"旧消息按 window_id 全量入 prompt"的结构证据（实测），但没有 annotated 快照证明具体一条旧需求被选中 | 机制最贴近 Ling 实现（取数层），但**无法解释**为什么"？"之后接的是旧需求而非同样在窗口里的别的内容——需要与 E3 组合 |
| 3 | **E6 模型自身对话惯性**：无记忆输入时 LLM 也偏好延续上文 | 四篇 human 都未提；无任何对照 | 作为**基线解释**必须存在：若空记忆也续接，则 E1-E5 都是过度归因。当前未被排除，故排第三但风险最高 |
| 4 | **E5 用户真实意图延续**：用户本来就在继续同一话题 | 反例中用户发的是"早上好"+"？"，doc01/02 均认为**无法确定**是否在延续 | 不能被排除（doc03 把它写成"确定不是"，证据不足）；需要 2×2 实验的"用户真延续"格来测 |
| 5 | **E2 位置/近因偏置**：旧事在 prompt 靠前/靠后被优先采纳 | 仅 doc04 把 recency 列为"弱信号"；无定位实验 | 论文上有失忆/长上下文位置效应，但本次产出未提供可复查的 Loculus 类证据；且被 doc04 明确降权 |
| 6 | **E4 提示词模板引导**：system 指令"保持连贯"鼓励续接 | 四篇均未给出具体模板文本证据 | 最缺证据；但在拿到基线 annotated 快照前不能排除 |

**最值得补的一组实验**（沿用判据 §10，现已细化）：
**2×2 对照回放**——因子 A：旧事片段是否存在于 annotated（有 / 无）；因子 B：用户本轮是否真的在延续旧事（显式回指 / 无锚点的"早上好+？"）。用同一批 S-xx 合成样本、同一提示词模板、真实模型（无 API 则整组标 SIMULATED 并只测管线）。四格观测：是否续接旧事、续接是否针对锚点。
- 若"有片段→续接"在 B=无锚点格也成立 → 支持 E1/E2/E6，反驳 E3/E5。
- 若只有 B=有锚点格续接 → 支持 E5（意图驱动），E1 只是必要不充分条件。
- 若 A=无片段格也续接 → E6 成立，所有基于"旧事在窗口里"的解释都要降级。
- 只有 E4 需要额外一组：改 system 模板（有/无"保持连贯"）再跑同一 2×2。
