## P2-1. 「无真实模型输出」纪律

| 项 | 内容 |
|---|---|
| 输入 | `out-baseline.jsonl`、`out-contrast.txt`、`out-variants.jsonl` 全文；三个 replay 脚本中产生输出文本的代码路径 |
| 观测字段 | 输出中是否存在形如「模型回复/assistant 回答/模型说」的字段或段落；其取值是否来自脚本内的模板、字符串拼接、随机/固定映射，而非任何模型 API 调用；脚本里是否有真实模型 API 调用（URL/SDK/密钥读取）及其返回是否进入输出 |
| 条件式结论 | 输出里的「回复」全部可由脚本内确定性模板 + 输入字段重算出、且无 API 调用证据 → 说明是脚本模拟，符合「无真实模型输出」纪律（前提：文档不得把它称成真实模型回复）；输出中出现无法由脚本重建的「回复」文本或明确的 API 调用落盘 → 说明存在真实模型输出或冒充，须查是否违反纪律；文档把模拟输出表述为「模型实测/模型回复」→ 假绿，无论脚本是否诚实 |
| 哪个错误实现会让这条红 | 脚本把硬编码的 `answer` 字典写成 `assistant_output` 字段（`names` 比实现强）；输出里混入真实模型文本但 README/报告按「回放」口径引用；把「编译出的提示词」误称为「模型回答」 |

## P2-3. 半成品变异：两半各自必须真红（核心）

| 项 | 内容 |
|---|---|
| 输入 | `out-variants.jsonl`（声明 12 条）、`03-variants.py`、`options/00-criteria.md` 中的 M 系列判据 |
| 观测字段 | 12 条中每条的：变异标签（去掉哪一半/保留哪一半）、`FAIL`/`PASS` 字段、判定理由字段、被测的断言名或条件、输入侧差异 |
| 条件式结论 | 存在成对的「只做 A 半」与「只做 B 半」输入，且两者都在**同一条判定逻辑**下得到 `FAIL`，而完整实现得到 `PASS` → 说明两个半变异真的各自触红，判据有区分力；只有标签不同但 `FAIL`/`PASS` 由与两半无关的固定字段决定 → 说明是**标签游戏**，判据没覆盖真正的不变量；两半都 `PASS` → 说明判据对这两半无区分力（按 AGENTS.md「半成品必须红」直接判红）；只红一半 → 说明另一半未被覆盖，结论要降到「仅覆盖一半」 |
| 反例输入（问「哪个错误实现会让这条红」） | 错误实现把 `PASS/FAIL` 写成输入 label 的查表（如 `variant in {"full"} → PASS` 其余 FAIL），与被测行为无关 → 标签变化确实改变颜色，但颜色不测量任何东西；错误实现只比较字段存在性而非内容 → 两半各自红但红的原因错误（须看字段值） |
| 哪个错误实现会让这条红 | 变异器「造了缺陷但没重算颜色」；判定逻辑 `try/except` 吞掉失败；变异前后没跑同一套断言；把「脚本抛异常」当成「测试红」 |

## P2-4. 2×2×2 对照的因子独立性

| 项 | 内容 |
|---|---|
| 输入 | `out-contrast.txt`、`02-contrast.py`、`01-samples.md`、`options/00-criteria.md` 中的因子定义 |
| 观测字段 | 8 个 cell 的输入侧快照；因子 A/B/C 各自 toggled 的字段；每 cell 实际发生变化的字段集合；是否存在「改 C 时 A 的旧事片段文本也变了」等交叉修改；输出中每 cell 的观测值 |
| 条件式结论 | 改某因子时只动该因子对应的输入字段、其余两因子字段字节级不变 → 说明因子正交，可把输出差异归因到该因子；改 C 时 A 字段联动变化 → 说明**混淆**，该 cell 的输出差异不能归因给单一因子，2×2×2 退化为若干未受控对照；两个 cell 输入完全相同但输出不同 → 说明有未记录的随机/状态源；两个 cell 输入不同但输出相同 → 说明输出对该因子不敏感，或判定逻辑只看了别的字段 |
| 哪个错误实现会让这条红 | 因子 C「引用注入」通过改写旧事片段的内容实现（从而同时动了 A）；toggle 用同一个可变对象导致前序 cell 污染后序；只打印因子标签不打印实际输入 → 独立性无法核查 |

| 条件式结论 | 记录里写的是「若 L 增长而调用数不变 → 说明长度未触发额外召回；若 L 不变而调用数增长 → 说明触发与长度无关」这类条件式 → 说明符合 M-11/M-12；只写「预期 N tokens / M 次调用」或单次数值 → 说明是复述式判据（AGENTS.md 明确禁止），须在报告中标注；完全没记录 → 说明 M-11/M-12 未落地，不能声称覆盖 |
